# 资产来源

本工程不随包分发图片、字体、音视频或第三方代码。仓库里的"资产"只有三类,
全部为人工编写。

## 设备档案(21 台)

`meilab/stealth/profiles.py`

UA 字符串、视口尺寸、字体清单、GPU 厂商与渲染器名称都是公开的技术标识,
按平台各自的常见配置手工整理。locale 与时区不出现在声明里,由 `sale_region`
经 `REGIONS` 表推导,这样不可能出现"UA 说 Android、时区在东京、locale 是 en-US"
这种自相矛盾的组合。

机型名(Pixel 7、SM-S911B、CPH2449 等)是厂商公开的型号标识,仅用于构造 UA。

## 鼠标轨迹样本(5 条)

`meilab/stealth/behavior.py` 的 `RECORDED_PATHS`

5 条归一化坐标序列(`[0,1]` 区间内的折线点),人工编写:近直线、上凸弧、
下凹弧、S 形、折线抖动各一条。**不是从真实用户采集的行为数据**,
不涉及任何人的生物特征。

生成轨迹时按 7:3 与三次贝塞尔混合,并叠加高斯抖动,避免每次轨迹完全一致。

## 站点规则(3 条 + 模板)

`rules/sites/`

针对公开页面 DOM 结构的 CSS 选择器描述,由本工程编写:

- `bilibili-video.yaml` —— B 站视频页
- `zhihu-question.yaml` —— 知乎问答页
- `template.yaml` —— 新站点起手模板

规则文件不含任何站点源码、样式表或媒体资源。

## 未使用的资产类型

以下内容本工程一概不包含,也不会引入:

- 字体文件(设备档案只记录字体**名称**,用于指纹一致性)
- 图片、图标、壁纸
- 音频、视频样本
- 第三方爬虫代码、代理列表、账号池
