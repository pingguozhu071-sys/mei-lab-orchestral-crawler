## 1. 代码来源

本工程为独立实现,不包含从其他项目复制的源码。

与姊妹工程 [kiana-crawler](https://github.com/pingguozhu071-sys/kiana-crawler) 的关系:
两者由同一来源维护,但**没有共享代码**。kiana 是 Windows 桌面产品(asyncio 内核、
PySide6 界面、PyInstaller 打包),本工程是多进程 CLI 与可嵌入库。两边在数据结构、
模块划分、并发模型上都不同。

真正借鉴过来的是**工程做法**,不是代码:

- 队列的租约 + 比较交换语义
- 出网请求的逐跳 SSRF 校验
- 三层脱敏的分层位置(日志 handler / 旁路 / 产物)
- 几条判据纪律(见 [工程经验记录](ENGINEERING-LESSONS.md) 末节)

这些做法属于工程常识范围,各自独立实现。

### 2.1 分发时需要单独注意的三项

**pymupdf** —— 可选依赖(`.[pdf]` extras)。其许可证为 AGPL-3.0。
如果你的分发场景不能接受 AGPL 的传染性条款,不要安装这个 extras,PDF 任务会按
「不支持」降级,其余通道不受影响。

**playwright / patchright** —— Apache-2.0 系许可。它们的浏览器二进制从官方发布渠道
下载,不随本工程分发。分发本工程时不需要包含浏览器。

**yt-dlp** —— 用于媒体通道的通用实现。它的版本更新频繁,行为随上游变化;
本工程只通过子进程调用,不修改也不内嵌其代码。

### 2.2 版本偏离

`opencv-python-headless` 的版本与原始工程规格不一致(`4.12.0.88` → `5.0.0.93`),
原因是原版本要求 `numpy<2.3.0`,与钉死的 `numpy==2.5.2` 冲突、无法安装。
差异原样记录在 [构建与运行](BUILD.md#6-已知构建问题),不隐瞒。

## 3. 数据处理边界

### 3.1 采集范围

- 只采集**公开可访问**的页面。
- 抓取前解析 `robots.txt`,`Disallow` 与 `Crawl-delay` 均遵守。默认开启,
  可显式关闭,但关闭即由使用者自行承担后果。
- 链接发现跳过 `/login`、`/signup`、`/register`、`/account` 等路径。
- 不绕过登录墙、付费墙、访问控制。需要登录态的场景只能由使用者提供自己的 cookie,
  引擎不代为获取。

### 3.2 个人信息

写入磁盘前会替换以下内容:

| 类别 | 处理方式 |
|---|---|
| 手机号 | 保留前 3 后 4,中间掩码 |
| 邮箱 | 保留首字符与域名 |
| IPv4 | 末段掩码 |
| 敏感 URL 参数 | 19 类(token / sign / w_rid / session / …),值替换为 `***`,参数名保留 |

脱敏覆盖三层:日志 handler、CLI/异常旁路、导出产物。递归深度 6 层。

**明确的例外**:任务队列表里的 URL **不脱敏**。它是下一次请求的凭据,
抹掉签名参数会导致续爬返回 403。这条边界是有意为之,不是遗漏。

### 3.3 限速

全局最小间隔 1.5 秒加随机抖动,叠加 robots 的 `Crawl-delay`、每域并发上限、
`Retry-After` 退避与域名冷却。这些是不可配置为「关闭」的默认行为——
只能调高,不能调低到 1.5 秒以下。

### 3.4 出网安全

所有出网请求(含每一次重定向)经过协议白名单与 DNS 解析后的地址判定:

- 拒绝环回、私网、链路本地、多播、保留地址
- 拒绝 CGNAT(`100.64.0.0/10`)等标准库未覆盖的段
- 还原数字字面量主机名(十进制/十六进制/八进制/省略段)
- DNS 判定缓存 90 秒,降低 rebinding 风险
- 重定向最多 10 跳,每跳复检

## 4. 第三方内容

- 设备档案里的 UA 字符串、字体名、GPU 渲染器名称是公开的技术标识,
  用于构造一致的浏览器特征,不涉及任何第三方素材的复制。
- 站点规则 YAML 是针对公开页面结构的描述,由本工程编写。
- 鼠标轨迹样本是人工编写的坐标序列,不是从真实用户采集的行为数据。

素材层面的说明见 [资产来源](ASSET-PROVENANCE.md)。

## 5. 使用者的责任

这套引擎把「抓什么、抓多少、怎么用」的决定权交给使用者。使用前请确认:

1. 目标站点的服务条款与 robots.txt 是否允许你抓取;
2. 抓取频率是否会给对方造成负担(引擎给的是下限,不是上限);
3. 抓到的内容是否涉及第三方权利(著作权、数据库权利、个人信息);
4. 你的使用场景是否需要遵守所在地区的具体法规。

引擎提供的安全机制(SSRF 闸、脱敏、限速)降低的是技术风险,
不构成对使用行为合法性的担保。
